# Python Sales Data Analyzer

## About the Project

A beginner-friendly sales data analysis project built using Core Python and CSV files. This project processes sales records to answer common business questions using Python fundamentals.

## Key Features

- Calculate total sales revenue
- Count total orders and units sold
- Analyze revenue by product category
- Analyze revenue by individual product
- Identify the highest-selling product by quantity
- Find the customer who spent the most
- Calculate daily sales revenue
- Calculate revenue between two dates
- Export electronics-category orders into a separate CSV file

## Technologies Used

- Python
- Jupyter Notebook
- CSV File Handling
- Python Standard Library

## Concepts Practiced

- Lists and loops
- Dictionaries
- Conditional statements
- Type conversion
- File handling
- Date-based filtering
- Data aggregation

## Project Files

- `ProjectSalesAnalyzer.ipynb` — Main analysis notebook
- `sales_data.csv` — Original sales dataset
- `electricals.csv` — Filtered electronics-category data

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `ProjectSalesAnalyzer.ipynb`.
4. Ensure `sales_data.csv` is in the same folder as the notebook.
5. Run the notebook cells in order.
